# Personal Portfolio Website

**Live Demo**: https://profdm-dev.github.io/portfolio

## Tools Used
- HTML5 (semantic structure)  
- CSS3 (custom styles)
- Tailwind CSS (CDN, responsive layout, styling utilities)

## Features Implemented
- Semantic HTML with `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`
- 3 pages: Home, Projects, Contact
- Navigation menu across all pages
- Contact form with validation (name, email, message, submit, reset)
- Project table (name, description, year)
- Ordered list (skills), unordered list (tools)
- Embedded profile, project images
- External CSS (`styles.css`) for hover/focus effects
- Tailwind CSS classes for responsive design
- Transition and hover animations on buttons/links
